# Веб-сайт с расписанием группы бТИИ-262 (Осенний семестр 2026-2027)

Современный сайт-расписание с минималистичным дизайном, адаптивной версткой, плавной анимацией, светлой и темной темами, регистрацией, сохранением данных в базе SQLite, защитой изменений паролем и разделением по 2 подгруппам.

## 🌟 Особенности

- **Темы оформления в минималистичном стиле**:
  - **Светлая тема**: чистый белый фон (`#ffffff`), мягкие карточки, голубые акценты (`#0284c7`, `#0ea5e9`).
  - **Темная тема**: глубокий темно-серый (`#0b0f17`, `#161f30`), неоновые голубые акценты (`#38bdf8`).
  - Плавные микро-анимации, карточки с эффектом парения, адаптация под мобильные устройства и ПК.
- **Подгруппы (только 1 и 2 подгруппы)**:
  - 1 подгруппа (15 студентов)
  - 2 подгруппа (14 студентов)
  - Переключатель отображает только вашу подгруппу («1 подгруппа» / «2 подгруппа»).
- **Числитель и Знаменатель**:
  - **Числитель (нечетные недели)**: темный бейдж (черный цвет в оригинальном расписании).
  - **Знаменатель (четные недели)**: синий бейдж и синяя полоса (синий цвет в оригинале).
  - По средам дисциплина «Архитектура и организация ЭВМ» стоит **только в числителе** (в знаменателе пар нет).
  - В качестве основного времени пар взяты реальные сдвинутые интервалы (`14:20 - 15:55`, `16:05 - 17:40`, `17:50 - 19:25`, `08:30 - 10:05`, `10:15 - 11:50`, `19:35 - 21:10`).
- **Адреса учебных корпусов (автоматические подписи)**:
  - Аудитории с индексом **/2** (напр. `102/2`, `302/2`, `310/2`, `405/2`) ➔ **Плехановская ул., 11 (Корпус 2)**
  - Аудитории с индексом **/1** (напр. `218/1`, `308/1`, `318/1`, `326/1`, `327/1`) ➔ **Московский просп., 14 (Корпус 1)**
  - Аудитории с индексом **/5** (напр. `406/5`) ➔ **Московский просп., 14 (Корпус 5)**
  - Аудитории без слэша (напр. `1301`, `1405`, `3110`, `3117`, `3222`, `Спортзал`) ➔ **ул. 20-летия Октября, 84 (Главный корпус)**
  - При создании или редактировании пары адрес университета подставляется автоматически при вводе аудитории!
- **🔐 Защита изменений расписания и ДЗ специальным паролем**:
  - Чтобы посторонние или одногруппники случайно не сломали общее расписание и не удалили домашку, на все операции редактирования установлен пароль.
  - Пароль хранится в защищенном локальном файле `.env` (или в переменных окружения хостинга) и **не публикуется на GitHub**.
  - При нажатии на «✏️ Изменить», «+ Добавить пару», «Сброс», «Добавить задание» или «Удалить ДЗ» открывается окно ввода пароля.
  - После первого успешного ввода браузер запоминает доступ, и в шапке сайта загорается индикатор **«Редактор: ВКЛ 🔓»**.
  - Можно выйти из режима редактора в любой момент кликом по кнопке в шапке сайта.
- **Общие Домашние задания группы**:
  - Список ДЗ открыт для просмотра всем студентам группы без необходимости обязательного входа.
  - Добавлять и удалять задания может старостат по паролю редактора.
  - Каждый студент может отмечать задания выполненными для себя.
- **Справочник группы**:
  - Полный список всех 29 студентов группы с разбивкой по 2 подгруппам.

## 🚀 Запуск и публикация

### 1. Локальный запуск (для себя)
Дважды щелкните по файлу `start.bat`. Он запустит сервер и откроет [http://localhost:8080](http://localhost:8080).

### 2. Сделать сайт доступным для всех прямо с ПК (за 30 секунд):
1. Запустите `start.bat`.
2. Запустите `share_online.bat`.
3. В окне появится публичная ссылка `https://xxxx.a.pinggy.link`, которую можно скинуть в Telegram-чат группы.

### 3. Размещение на постоянном бесплатном сервере (24/7):
Проект полностью готов для деплоя на **Render.com** или **Railway.app**:
- Добавлены файлы `requirements.txt`, `Procfile`, `Dockerfile`.
- При необходимости свой пароль редактора можно задать в настройках хостинга в переменной `ADMIN_PASSWORD`.
