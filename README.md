# Расписание группы бТИИ-262

Локальный веб-сервер и интерфейс расписания занятий (осенний семестр 2026–2027).

---

## ⚡ Быстрый запуск

- **Локально:** запустить `start.bat` или вручную:
  ```bash
  python server.py
  ```
  Интерфейс откроется по адресу: [http://localhost:8080](http://localhost:8080).

- **Временный доступ для группы:**
  1. Запустить `start.bat`.
  2. Запустить `share_online.bat` (поднимает SSH-туннель через `a.pinggy.io:443`).
  3. Скопировать выданную `https://...pinggy.link` ссылку.

### Автоопределение адресов корпусов по номеру аудитории
- `*/1` (напр. `218/1`, `318/1`) ➔ **Корпус 1** (Московский просп., 14)
- `*/2` (напр. `102/2`, `310/2`, `405/2`) ➔ **Корпус 2** (Плехановская ул., 11)
- `*/5` (напр. `406/5`) ➔ **Корпус 5** (Московский просп., 14)
